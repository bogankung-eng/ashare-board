# A股行情看板 · 短线涨停接力复盘工具

盘后复盘聚合看板：把涨停池、龙虎榜、资金流、市场广度统一成一份可筛选、带结论的 HTML 报告。

## 功能

- **情绪面板**：涨停/跌停/炸板/炸板率/连板高度/涨跌家数/活跃度 → 情绪标签（加强/修复/退潮/震荡）
- **涨停池连板梯队**：空间板→3板→2板→首板，字段含涨停原因、换手率、封板资金、首封时间、炸板次数
- **多条件筛选**：盘口行业 / 连板数 / 换手率区间 / 首封时间档 / 炸板次数
- **个股分析**：五维延续性评分（封板强度×资金×换手×位置×地位）+ 次日应对策略 + 风控位
- **题材分析**：行业聚类、阶段判断（试盘/启动/发酵/高潮）、龙头识别、高低切观察
- **复盘闭环**：昨日涨停晋级率、晋级/断板名单、龙虎榜净买 TOP、板块资金流流入/流出

## 使用

```bash
# 1. 采集盘后数据（非交易日/重复采集自动跳过）
python _collect.py [--date=YYYYMMDD] [--force]

# 2. 生成看板
python _gen_board.py [--date=YYYYMMDD]

# 3. 打开 board.html（或部署 index.html）
```

依赖：Python 3.10+，`pip install akshare`

## 数据源

- 涨停/跌停/炸板池、龙虎榜、昨日涨停：东方财富（akshare）
- 市场广度：乐咕乐股（轻量，仅最新交易日）
- 板块资金流：同花顺（仅最新交易日）

## 目录

```
_collect.py   采集器：数据 → SQLite + JSON 快照
_gen_board.py 看板生成器：SQLite → 单文件静态 HTML
data/         本地数据库与快照（不入库）
index.html    最新看板（部署物）
```
